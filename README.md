# Air Quality Prediction System

## Overview
This project is a Machine Learning based Air Quality Index (AQI) Prediction System developed using Python. The system analyzes air quality data and predicts AQI levels using different ML algorithms.

## Features
- Data preprocessing and cleaning
- AQI prediction using Machine Learning
- Multiple model comparison
- Data visualization using graphs
- User-friendly prediction interface
- Performance evaluation of models

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
The project uses air quality dataset containing different pollutant parameters used for AQI prediction.

## Machine Learning Models
- Linear Regression
- Random Forest
- Decision Tree
- Other regression models for comparison

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Feature Selection
4. Model Training
5. Model Evaluation
6. AQI Prediction
7. Visualization

## Output
The system predicts Air Quality Index values and displays air quality categories such as:
- Good
- Moderate
- Poor
- Very Poor
- Severe

## How to Run
1. Clone the repository
2. Install required libraries
3. Open the notebook file
4. Run all cells
